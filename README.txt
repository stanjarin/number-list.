Number List V9 — clean rebuild from the last known-good V5 force engine.

Normal:
• Launch = current note.
• Tap “Notes” = All iCloud library.
• Tap a library row = open that list.
• Hold a row ~0.7 sec = edit it.
• Bottom-right pencil = new list.
• Top-right Save = actually creates/saves the list.
• Cancel abandons a new draft; it creates no ghost note.
• Export/Import backs up the local library.

Force:
• Hold bottom-left, tap exactly two digits.
• Hold top-right calls Number List Voice Shortcut.
• ?n=NN is still accepted.

No service worker is included, deliberately, to reduce stale-cache trouble.
